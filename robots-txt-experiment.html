Robots.txt Practical Testing & Web Crawling Experiment

Project Overview

This project presents a practical experiment conducted to understand how robots.txt commands affect crawler access to web pages.

The experiment was conducted using a GitHub Pages website and a robots.txt testing tool.

Objectives

  • Understand how the Disallow command works.
  • Test the Allow command.
  • Compare crawler-specific User-agent rules.
  • Test the wildcard User-agent.
  • Examine the role of Sitemap and comments.
  • Observe the effect of Crawl-delay in the testing environment.
  • Understand the importance of using the exact URL path.

Practical Experiments

1. Disallow

The Disallow command was used to block access to a specific directory.

2. Allow

An Allow rule was used to permit access to a specific page inside a disallowed directory.

3. User-agent

Different rules were tested for Googlebot and Bingbot to observe crawler-specific behavior.

4. User-agent: *

The wildcard User-agent was tested to apply the rule to crawlers generally.

5. Comments

A comment was added to the robots.txt file to confirm that comments do not change the access rule being tested.

6. Sitemap

A Sitemap URL was included in the robots.txt file as part of the experiment.

7. Crawl-delay

A Crawl-delay value was included for observation in the testing environment.

Key Learning

The experiment showed that the exact URL path is important when writing a robots.txt rule. A rule must correspond to the actual path that is being tested.

The experiment also demonstrated how crawler-specific rules can produce different results depending on the User-agent being tested.
